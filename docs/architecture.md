# Архитектура

IPA Shuttle является приложением Tauri v2 только для macOS. React/TypeScript реализует два экрана, Apps & IPA и Install, и вызывает типизированные команды Tauri. Интерфейс не знает путей встроенных движков и аргументов командной строки.

## Исполняемые слои

- `src/app`, `components`, `features`: сценарии интерфейса и общее состояние библиотеки IPA.
- `src/i18n`: полные EN/RU-каталоги; отсутствующие и неиспользуемые ключи останавливают сборку.
- `src/lib/api.ts`: единая типизированная граница Tauri.
- `src-tauri/src/core`: устройства, приложения, вход, библиотека IPA, установка, хранение, ошибки и структурные журналы.
- `src-tauri/src/engine`: разрешённые пути движков и запуск через массив argv, `ProcessRunner`, очищенное окружение и таймауты.
- `third_party/ipatool-shuttle`: изолированный движок входа и скачивания с MIT-лицензией.

Команды Tauri остаются тонкими и выносят блокирующую работу из потока интерфейса. Первое сканирование не запрашивает `DynamicDiskUsage`: сразу возвращает строки из XML, затем отдельно загружает иконки. Размеры данных загружаются только по явному запросу в отменяемой фоновой операции, привязанной к поколению сканирования. Общее хранилище библиотеки IPA является источником данных для обоих экранов.

## Данные

- IPA: `~/Library/Application Support/IPA Shuttle/Library/`.
- Кэш иконок: `~/Library/Application Support/IPA Shuttle/Icons/`.
- Manifest: `~/Library/Application Support/IPA Shuttle/manifest.json`.
- Журнал: `~/Library/Logs/IPA Shuttle/app.log`.

Manifest и метаданные иконок используют строгие схемы. Изменения manifest выполняются под одной блокировкой и записываются атомарной заменой с правами `0600`. Пути IPA канонизируются, ограничены библиотекой приложения и перед установкой проверяются на непустую ZIP-сигнатуру. Символьные ссылки manifest и иконок отклоняются.

Журналы являются JSON lines, очищаются от секретов до записи, хранятся 7 дней и ротируются по 5 МБ с тремя архивами. Файлы имеют права `0600`, каталоги `0700`.

## Вход

Пароль и коды 2FA существуют только в памяти и передаются процессу входа через stdin. Дочерний процесс завершается и ожидается при отмене, таймауте и освобождении владельца. Session IPC использует уникальный файл `0600` в каталоге `0700`; файл удаляется при каждом исходе операции.

Сохранённая сессия использует ровно один элемент Keychain процесса IPA Shuttle: `com.ipashuttle.apple-session.v2/active`. Действие Use saved session один раз читает его в `AuthSessionManager`; скачивания используют только этот кэш в памяти. Запуск, навигация, сканирование и обновление устройства не читают Keychain.

## Граница платформы

Штатный capability Tauri разрешает только `core:default`. Asset protocol ограничен кэшем иконок; CSP запрещает объекты, фреймы, формы и удалённое содержимое. Путь встроенного движка должен вести к исполняемому обычному файлу внутри разрешённого каталога Resources.
