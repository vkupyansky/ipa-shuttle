# Тестирование

Полный набор проверок выполняется из корня репозитория. iPhone нужен только для отдельного сценария на устройствах ниже.

```bash
pnpm install --frozen-lockfile
pnpm lint
pnpm typecheck
pnpm test
pnpm test:coverage
pnpm i18n:check
pnpm build
pnpm knip
pnpm audit --audit-level=low
cargo install cargo-audit@0.22.2 --locked
cargo install cargo-machete@0.9.2 --locked
cd src-tauri
cargo fmt --check
cargo test --release
cargo clippy --release -- -D warnings
cargo machete
cd ../third_party/ipatool-shuttle
test -z "$(gofmt -l .)"
go test ./...
go vet ./...
go run golang.org/x/vuln/cmd/govulncheck@v1.6.0 ./...
cd ../../src-tauri
cargo audit
```

Frontend-тесты проверяют переключение языка, состояния входа, сортировку/поиск, сохранение выбора, синхронизацию общей библиотеки, журнал действий, удаление отсутствующего IPA, обновление устройства, батарею и тексты ошибок.

Rust-тесты проверяют XML и размеры данных, иконки, строгое и атомарное хранение, границы путей, очистку журналов, количество обращений к сессии, устаревшие операции, понятные ошибки и завершение/ожидание процессов по таймауту. Тесты стороннего Go-движка покрывают запросы к Apple, вход и скачивание, включая отсутствие пароля в сохранённой сессии.

Пороги покрытия: statements 70%, branches 60%, functions 65%, lines 70%. Tauri bootstrap и интерактивное окно входа исключены из frontend-покрытия; их состояние и API проверяются ниже границы интерфейса.

Точечная проверка release-сборки: `scripts/check-memory.sh`. Полное покрытие GUI средствами Miri/ASan непрактично для WebKit/Tauri; чистые Rust-модули проверяются отдельно, а скрипт при необходимости вызывает macOS `leaks`.

## Сценарий на устройствах

Используйте только собранное `src-tauri/target/release/bundle/macos/IPA Shuttle.app`:

- Запустите приложение и проверьте отсутствие запроса Keychain.
- Обновите iPhone, просканируйте приложения и проверьте имя, bundle ID, версию, размеры, батарею, иконки/монограммы и EN/RU-интерфейс.
- Убедитесь, что список появляется до размеров данных. Нажмите Load data sizes и проверьте сохранение выбора, поиска и сортировки.
- Войдите в Apple ID, завершите 2FA и при необходимости сохраните сессию.
- Скачайте два IPA; запрос Keychain не должен появляться при скачивании, сканировании, обновлении, навигации или сверке библиотеки на экране установки.
- Удалите один IPA в интерфейсе, проверьте обновление обоих экранов и скачайте файл заново.
- Перезапустите приложение, один раз нажмите Use saved session и скачайте ещё один IPA без повторного запроса Keychain.
- Подключите целевой iPhone и установите скачанный IPA.
- Удалите запись отсутствующего файла из manifest и убедитесь, что она не появляется после перезапуска.
- Очистите журнал с фильтрами All, Warnings и Errors; прежние записи не должны возвращаться.

Готовность выпуска подтверждается полным сценарием входа, скачивания, удаления/повторного скачивания и установки в собранном приложении.
